# Spot Hockey — ゲーム説明・得点システム

## ゲーム概要

マウスで操作するパドルを使い、CPU 相手にパックを打ち合うエアホッケーゲームです。
観戦者がリアルタイムでスコアを確認できるよう、得点は画面左上に常時表示されます。

---

## 操作方法

| 操作 | 内容 |
|------|------|
| マウス移動 | パドルを動かす（画面左半分のみ） |
| ゲーム中 | Menu ボタンで難易度選択に戻る |
| ゲーム中 | Launcher ボタンでゲーム一覧に戻る |

---

## ゲームルール

- **先取 5 ゴール**で勝利（コールドゲーム）
- **2 分**経過した時点でゴール数が多い方が勝利（同点は CPU の勝ち）
- ゴールを決めるたびにパックがセンターに戻り、再開します
- フィールド中央の**センタースポット（黄色円）**にパックが触れると、2 秒間パックが加速します

---

## 得点システム

ゲーム終了後に**計上画面**で得点の内訳が表示されます。

### 基本式

```
合計スコア = ゴール点 + ヒット点 + タイムボーナス
```

### 内訳

| 項目 | 計算式 | 例 |
|------|--------|-----|
| ゴール点 | ゴール数 × 100点 | 3ゴール → 300点 |
| ヒット点 | ヒット数 × 10点 | 15ヒット → 150点 |
| タイムボーナス | 残り秒数 × 難易度係数（勝利時のみ） | 45秒残 × 2 → 90点 |

> **ヒット**とは、プレイヤーのパドルがパックを弾いた回数です。  
> 積極的なプレイほどスコアが伸びます。

### 難易度別タイムボーナス係数

| 難易度 | 係数 | 45秒残しの場合 |
|--------|------|--------------|
| EASY | × 1 | 45点 |
| NORMAL | × 2 | 90点 |
| HARD | × 3 | 135点 |

HARD は CPU が強いぶん、速く勝つほどタイムボーナスが大きく加算されます。

---

## 計上画面の見方

ゲーム終了後、数秒かけて得点の内訳がアニメーション表示されます。

```
YOU WIN!

ゴール   3 × 100  =  300点
ヒット  15 ×  10  =  150点
タイム  45秒 × 2  =   90点
────────────────────────────
TOTAL              540点

[Play again]  [Difficulty]
```

> 時間切れで終了した場合は **「— TIME UP —」** とゲーム種別（YOU WIN! / CPU WINS）が表示されます。

---

## スコア記録とホーム画面

ゲーム終了後に**ランチャー画面に戻ると**、直近のプレイ結果がリスト表示されます。

```
RECENT RESULTS
Spot Hockey   WIN   540点   14:30
```

運営はランチャー画面のスクリーンショット 1 枚で結果を記録できます。

---

## スコア上限の目安

| 条件 | 最大スコア（概算） |
|------|--------------------|
| 5ゴール早期勝利 + 多ヒット + HARD | 500 + ヒット分 + 270以上 |
| NORMAL で 2 分フルプレイ勝利 | ゴール点 + ヒット点 + タイムボーナス |
| 敗北時 | ゴール点 + ヒット点（タイムボーナスなし） |
